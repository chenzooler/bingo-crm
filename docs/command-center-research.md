# מחקר קומפוזיציה — מרכז שליטה לכרטיס הלקוח (05/08/26)

מקורות: Attio (record page + highlight widgets + activity timeline 2026) · Front (compact header + context rail) ·
Aircall (Workspace 3 עמודות + widget-size לשיחה) · Dialpad (בר שליטה תחתון + Live Coach cards ימין) ·
Close (פיד הפעילות כעמוד השדרה + בר שיחה צף) · Linear (צפיפות 4px + אופסיטי 40-60% + מקלדת) ·
Ramp/Stripe/Mercury (מספר-גיבור אחד, מספרים טבולריים, בנטו).
הערה: Mobbin MCP דורש אימות OAuth (לא זמין בסשן לא-אינטראקטיבי) ו-mobbin.com חוסם דפדפן מוטמע —
המחקר בוצע דרך מקורות רשת + תיעוד המוצרים.

## דפוסי הקונצנזוס (2025-26)
1. פיד הפעילות הוא עמוד השדרה של כל תצוגת ליד (Close, Attio) — ממוזג, מסונן, כרונולוגי.
2. שליטת שיחה = יחידה עצמאית נצמדת (בר תחתון / אריח) ששורדת ניווט (Close, Dialpad, Aircall).
3. מדדי-גיבור מעל הקפל: עד 6 אריחים, מספר אחד שהתפקיד בא בשבילו (Attio, Ramp, Mercury).
4. מתכון צפיפות: גריד 4px · היררכיית טקסט באופסיטי (100/60/40%) · רוויה שמורה לסטטוס בלבד ·
   ספרות טבולריות לכסף · progressive disclosure בהובר (Linear).
5. מקלדת-first: פלטת ⌘K, מקשי ספרות, רמז הקיצור על הכפתור עצמו.
6. עזרת תסריט/AI = שכבת כרטיסים בצד ימין, נסגרת — לא בתוך הטופס (Dialpad).
7. דארק כזהות: בסיס כמעט-שחור (לא ‎#000), אקסנט אחד, גלואו רק למצבים חיים (Linear, Ramp).

## שלוש הקומפוזיציות שנגזרו

### A · "קוקפיט תלת-פאנלי" (Aircall/Dialpad/Front/Close)
עמודת עבודה ~55% (השאלון החי כתסריט נגלל — שאלה נוכחית ענקית, שנענו דוהות מעלה) ·
רצועת הקשר ימנית ~30% (מספרים + click-to-call, תוצאות גופים, משימות, פיד מיני, כרטיסי-ניתוב קופצים) ·
בר שיחה תחתון קבוע (טיימר/השתק/ניתוק/סיווג 1-4/הליד הבא) שזוהר בשיחה חיה.
מצטיין במצב חיוג רציף; מתקפל יפה ברוחב בינוני.

### B · "בנטו מדדי-גיבור" ⭐ הנבחר — זה כיוון E (Attio/Ramp/Stripe/Mercury)
כותרת מלאה (שם, פסק-דין קטלוג, פעולות) → טאבים (4 עמודי הכרטיס) →
גריד בנטו 12 עמודות: אריח-גיבור (הסכום + מד ציון תיק) · השאלון החי (שאלה דומיננטית בסגנון C) ·
דיוקן הלקוח (רצועת שדות צד) · בדיקות זכאות (ברים חיים פר-גוף) · מדדים (KPI) · פיד פעילות חי.
בשיחה חיה אריח KPI מתמורף לאריח-שיחה (טיימר+ניתוק) — "המספר-הגיבור הופך לשיחה".
החריגים מקבלים את הצבע הרווי היחיד על המסך.

### C · "עמוד שדרה של תסריט + אי-פעולה צף" (Close/Linear/Mercury)
עמודה אחת ~840px: בלוק סיכום-ליד → השאלה הנוכחית כיחידה הדומיננטית (יחס Mercury-balance) →
שורות שנענו נדחסות לשורת-Linear אחת (הובר מרחיב) → פיד ממשיך מטה.
הטלפוניה כולה באי צף תחתון-מרכז (Dynamic Island): רגוע="חייג Enter", חי=טיימר+ניתוק+סיווג.
הקשר רחב במגירה (LeadDataSheet) ולא בפאנל קבוע. הכי טהור-מקלדת; מסתיר רוחב תיק.
