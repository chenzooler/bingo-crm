## 1. סדר השאלון — בדיוק כך

### שלב א' — פתיחה
1. **שם פרטי + שם משפחה** (השאלות הראשונות!)
2. **מטרת ההלוואה**

### שלב ב' — בדיקת נתוני אשראי (שאלות הסינון)
כל שאלה עם שתי תשובות — תקין / שלילי. **תשובה שלילית אחת ⇒ הלקוח מקוטלג "חיווי אשראי שלילי"**:

| # | שאלה | תשובה תקינה | תשובה שלילית |
|---|---|---|---|
| 1 | האם היו בעיות בהוצאה לפועל? | הכל תקין | היו בעיות |
| 2 | האם חזרו צ'קים / הוראות קבע / הלוואות / מסגרות אשראי בשנתיים האחרונות? | לא חזר כלום | היו חזרות |
| 3 | האם החשבון מוגבל כרגע או היה מוגבל בשנתיים האחרונות? | חשבון תקין | חשבון מוגבל |
| 4 | האם ביצעת מחיקה או שיפור ל-BDI? | לא ביצעתי | ביצעתי ⇒ שלילי |
| 5 | האם יש בבעלותך כרטיס אשראי? | ישראכרט / כאל / מקס | **רק דיירקט** או **אין כרטיס בכלל** ⇒ שלילי |
| 6 | מה גובה מסגרת האשראי? | מעל 5,000 | מתחת ל-5,000 ⇒ שלילי |
| 7 | האם ביצעת בדיקה להלוואה לפני שפנית אלינו? | בבנק שלי / בנק ירושלים / ישראכרט / כאל / מקס / הפניקס / קרדיט 24 / אחר | (מידע, לא פוסל) + **הערות לבדיקות** |

**קטלוג חיווי אשראי: שלילי / לא ידוע / חיובי.**

### שלב ג' — זיהוי + רמזור
1. מין (זכר/נקבה) · 2. תאריך לידה · 3. אישור הלקוח לבדיקת BDI
4. **בדיקת רמזור (משודרת באוטומציה)** → ירוק / צהוב (כתום) / אדום

### שלב ד' — חוקי הקטלוג (הלב!)
| רמזור / מצב | מה מציעים | קטלוג הלקוח |
|---|---|---|
| 🔴 אדום | כלום — אין מה לעשות | **לקוח אדום** |
| 🟡 צהוב/כתום | רק הלוואה כנגד רכב | **לקוח צהוב רכב** |
| 🟢 ירוק + שאלות תקינות | גם כל מטרה וגם רכב | **לקוח תקין** |
| שאלות שליליות + יש רכב + רמזור ירוק/כתום | ממשיכים להלוואה כנגד רכב | **לקוח שלילי עם רכב** |

**מסלול השלילי**: אם ענה שלילי על אחת מהשאלות ⇒ **מיד** שואלים "יש בבעלותך רכב?" ⇒
שאלות זיהוי (לידה וכו') ⇒ בדיקת רמזור ⇒ רק אם יש רכב + רמזור ירוק/כתום ⇒ מתקדמים לרכב.

### שלב ה' — לקוח תקין בלבד
1. מצב תעסוקתי (שכיר / עצמאי / מקבל קצבה / לא עובד / פנסיונר)
2. יש נכס בבעלותו? (יש / אין)
3. **עיר מגורים** — הקלדה פותחת רשימה חכמה של **כל** יישובי ישראל (כולל ערים ערביות וכפרים)
4. **רחוב** — הקלדה פותחת את **כל** רחובות ישראל
5. **מיקוד** — מתמלא **אוטומטית** לפי עיר+רחוב
6. **תסריט שיחה ללקוח** (קודם התסריט!)
7. **חתימה על הסכם התקשרות** (אחרי התסריט!)

### שלב ו' — אחרי החתימה
1. תאריך הנפקת ת.ז · 2. סטטוס משפחתי (רווק/נשוי/גרוש/אלמן/ידוע בציבור) · 3. ילדים מתחת 18
4. מקום עבודה / תפקיד (אפשר רק תפקיד) · 5. ותק · 6. נטו חודשי · 7. נטו בן/בת זוג
8. קרן פנסיה/השתלמות? (כן / לא / לא ידוע / לקוח צעיר) → אם כן: חברת ביטוח (עם לוגו!) + סכום משוער
9. סוג מגורים (שכירות / בעלות / בעלות+משכנתא / אצל ההורים) → אם שכירות/משכנתא: החזר חודשי
10. רכב בבעלות? (כן / כן משועבד / לא)
    - כן → מעל/מתחת 2013 → אם מעל: **מה השנה המדויקת**
    - משועבד → מאיפה: מימון ישיר / פמה / מזרחי טפחות / שעבוד אחר → אחר: שדה חופשי

### שלב ז' — נתונים בנקאיים
1. **בנק** — רשימת כל הבנקים בארץ **עם לוגו של כל בנק ליד השם**
2. **סניף** — רשימת כל הסניפים בארץ לפי בנק, עם חיפוש חכם: מקליד "675" ⇒ קופץ "675 כפר יונה"
3. מספר חשבון
4. הלוואות פעילות? מאיפה (כל גופי המימון + בנק פרטי) + הערות

## 2. מבנה כרטיס הלקוח — עמודים (מעבירים ביניהם!)

| עמוד | תוכן |
|---|---|
| **1 — תסריט שיחה** | השאלון המלא כשהתסריט יפה מול העיניים; שליחת הסכם / WhatsApp / מיילים; רואים ומוסיפים משימות ופעילויות |
| **2 — בדיקות זכאות** | אזור הבדיקות בלבד, עם התוצאות |
| **3 — תיעוד** | הכל כרונולוגי: פעילויות, משימות, שיחות, הקלטות — הכי מסודר שיש |
| **4 — כספים** | חשבוניות שהוצאו, כל הנתונים הכספיים + הוצאת חשבונית |

### הכותרת העליונה של כל כרטיס — חובה, מודגש חזק:
**צבע הלקוח** (מערכת הצבעים של חן):
- 🟢 **ירוק** — מתאים להלוואה לכל מטרה וגם לרכב
- 🔵 **כחול** — יכול לקבל רק הלוואה כנגד רכב
- 🟠 **כתום** — מתאים רק לרכב **אבל אין לו רכב**
- 🔴 **אדום** — לא מתאים לכלום

בנוסף בכותרת: **תמצית קצרה** — מה הלקוח רצה · מתי הייתה השיחה האחרונה · האם יש משימה פעילה · מתי נכנסו לכרטיס בפעם האחרונה **ומי**.

## 3. דרישות עיצוב וחוויה (לא משא ומתן)
- כל שדה עם **אייקון מעוצב** בשפת בינגו · לוגו אמיתי לכל בנק וכל חברת ביטוח
- **לוגיקה מותנית בכל מקום** — שדה נפתח רק כשהשדה שמעליו מצדיק
- כל שדה ממוקם עם **מחשבה עמוקה למה בדיוק שם**
- "המערכת הכי מתקדמת ודיגיטלית שיש, חווית נציג הכי טובה שיכולה להיות"
- עיצוב **פורץ דרך** שלא נראה בשום מערכת — לא עוד SaaS לבן גנרי
- חן מוכן לשלם על כלים/תוספות/דאטה כדי להגיע לרמה הזו
